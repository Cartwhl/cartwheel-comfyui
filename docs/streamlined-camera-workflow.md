# Quick workflow

1. Install the extension and import [Cartwheel Motion to Video](../Cartwheel-Motion-to-Video.json).
2. Choose Performance Capture, Swing Choreo, or Load Motion. Only the selected source runs. For local reuse, open Load Motion → Saved jobs.
3. Keep Preview or Generate on Preview camera and run. Fresh Cartwheel motion sources consume Cartwheel credits; local scene editing and rendering do not submit model jobs.
4. Edit the camera in Scene, using the camera view to judge the shot. Split timeline blocks for multiple moves, or use one full-length block.
5. Name and save a scene to keep an experiment. Saved scenes appear in the local Saved jobs catalog.
6. Add optional references and choose the video model in Prepare Video References. Additional camera passes and endpoint images are opt-in.
7. Select Generate final video and run. The selected native generator uses Comfy credits. Review the result and optional side-by-side comparison.

For the complete walkthrough, use [Overview](../OVERVIEW.md). For account setup and installation, use the [README](../README.md).
