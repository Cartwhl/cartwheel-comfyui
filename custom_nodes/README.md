# Cartwheel node package

This directory contains the Python nodes and browser editor for [Cartwheel ComfyUI](../README.md).

Copy the entire directory into a named extension folder under ComfyUI’s `custom_nodes/`, install `requirements.txt` with ComfyUI’s Python, and restart ComfyUI. See the [setup instructions](../README.md#manual-setup) for details.

The [workflow JSON](../Cartwheel-Motion-to-Video.json), [overview](../OVERVIEW.md), and [technical reference](../TECHNICAL_REFERENCE.md) are at the repository root. They are not needed inside the installed extension directory.
