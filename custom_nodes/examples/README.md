# Compatibility examples

For the complete current workflow, use [Cartwheel Motion to Video](../../Cartwheel-Motion-to-Video.json) at the repository root. It starts in Preview camera mode.

Files in this directory are smaller examples and compatibility fixtures used by the checks. They are not separate supported workflows. Files named `history-*` illustrate retired account-history behavior; the current workflow uses Load Motion → Saved jobs for local results.

File inputs and prompts use blank or synthetic placeholders. These examples contain no credentials or user media.
